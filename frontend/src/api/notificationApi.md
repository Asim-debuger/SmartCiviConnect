This file manages API calls for user notifications.

-   **`listNotifications(params)`**: Fetches a list of notifications for the current user.
-   **`markNotificationRead(id)`**: Marks a single notification as read.
-   **`markAllNotificationsRead()`**: Marks all of the user's unread notifications as read.
-   **`deleteNotification(id)`**: Deletes a notification.

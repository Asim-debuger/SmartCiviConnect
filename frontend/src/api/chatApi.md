This file contains functions for handling real-time chat and messaging between users.

-   **`listInbox()`**: Fetches the user's inbox, which contains a list of all their conversations.
-   **`openConversation(userId)`**: Initiates a new conversation with a specific user or opens an existing one.
-   **`listMessages(id)`**: Retrieves all messages from a specific conversation by its ID.
-   **`sendMessage(id, payload)`**: Sends a new message to a specific conversation.

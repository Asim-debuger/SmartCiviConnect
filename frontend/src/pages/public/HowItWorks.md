Public How It Works page explaining the end-to-end civic response workflow.

**Workflow flow**
- Five-step vertical timeline: Citizen submit, Admin verify, Officer assign, Staff work, Citizen verify.
- Each step shows actor, title, description, and lucide-react icon.
- Connector arrows between steps.

**Visual workflow bar**
- Horizontal scrollable strip showing the same five steps in a single row with connectors.
- Enables quick visual scanning of the process.

**Components used**
- `PageHero` for the page header.
- `Container` for layout.
- Lucide icons: `ArrowDown`, `BadgeCheck`, `ClipboardEdit`, `HardHat`, `SearchCheck`, `UserCheck`.

**Data**
- All workflow steps are static inline data.

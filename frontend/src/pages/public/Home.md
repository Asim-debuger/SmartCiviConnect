Public landing page that composes multiple reusable sections into the home experience.

**Sections rendered**
- `HeroSection` — top hero banner.
- `PlatformVisionSection` — platform vision statement.
- `StatsSection` — key metrics.
- `CategoriesSection` — complaint categories.
- `HowItWorksSection` — workflow overview.
- `FeaturesSection` — feature highlights.
- `RolesSection` — user role overview.
- `MarketplacePreview` — jobs/professionals preview.
- `CTASection` — final call to action.

**Data**
- Purely compositional; all content is delegated to child section components.
- No local state or data fetching.

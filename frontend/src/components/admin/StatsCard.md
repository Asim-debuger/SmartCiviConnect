This file defines a simple, reusable card component for displaying a single statistic.

-   **Functionality**: It serves as a visual element on a dashboard to highlight a key metric.
-   **Props**: It accepts a `title` (the name of the metric), a `value` (the number or string to display), and an `icon` (a Lucide React icon component).
-   **Layout**: The component arranges the icon, title, and value in a clean, card-style format, making it suitable for dashboards and overview pages.

This file defines a simple, static component to display the steps of a complaint process.

-   **Functionality**: It renders a hardcoded list of steps in a vertical timeline format.
-   **Data**: It uses a predefined `steps` array (e.g., "Complaint Submitted", "Verified By Admin").
-   **Note**: This appears to be a simplified or older version. It statically renders each step and does not reflect the actual progress of a specific complaint. The component at `src/components/citizen/ComplaintTimeline.jsx` is a more dynamic and advanced implementation.

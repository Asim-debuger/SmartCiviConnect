This file defines a simple dropdown component for selecting a complaint's priority level.

-   **Functionality**: It renders a `<select>` element populated with a predefined list of priority levels.
-   **Props**:
    -   `value`: The currently selected priority.
    -   `onChange`: The function to call when the user selects a new priority.
-   **Data**: It contains a hardcoded array of `priorities`: "Low", "Medium", "High", and "Emergency".

This file defines a modal that is displayed after a complaint has been successfully submitted.

-   **Functionality**: It serves as a confirmation to the user, showing them their unique complaint ID.
-   **Props**:
    -   `complaintId`: The ID of the newly created complaint to display.
    -   `close`: A function to be called when the user clicks the "Continue" button to close the modal.
-   **Layout**: It's a centered modal with a success message and the complaint ID displayed prominently.

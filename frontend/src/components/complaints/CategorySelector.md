This file defines a simple dropdown component for selecting a complaint category.

-   **Functionality**: It renders a `<select>` element populated with a predefined list of complaint categories.
-   **Props**:
    -   `value`: The currently selected category.
    -   `onChange`: The function to call when the user selects a new category.
-   **Data**: It contains a hardcoded array of `categories` like "Road Damage", "Garbage", "Potholes", etc.

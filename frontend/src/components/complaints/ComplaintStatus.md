This file defines a component that renders a colored status badge for a complaint.

-   **Functionality**: It displays the complaint's status string inside a styled `<span>` with a background color that corresponds to the status.
-   **Props**: It accepts a `status` string (e.g., "Pending", "Completed").
-   **Styling**: It uses a `styles` object to map each status string to a specific set of Tailwind CSS classes, providing visual consistency for statuses across the application.

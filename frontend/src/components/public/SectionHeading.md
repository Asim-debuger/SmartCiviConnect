This file defines a reusable component for creating standardized section headings.

-   **Functionality**: It provides a consistent structure for titles, subtitles (eyebrows), and descriptions used across different sections of the website.
-   **Props**:
    -   `eyebrow`: An optional small, uppercase text that appears above the main title.
    -   `title`: The main heading text.
    -   `description`: An optional paragraph of text that appears below the title.
    -   `light`: A boolean prop that adjusts the text colors for use on dark backgrounds.
    -   `align`: A string ('center' or 'left') to control the text alignment. Defaults to 'center'.
-   **Usage**: This component is used extensively in the landing page sections to ensure a consistent look and feel.

This file defines a reusable hero section component for generic content pages.

-   **Functionality**: It creates a visually appealing header for pages, distinct from the main landing page's hero section.
-   **Props**:
    -   `eyebrow`: An optional small, uppercase text that appears above the title.
    -   `title`: The main page title.
    -   `description`: An optional descriptive paragraph that appears below the title.
-   **Layout**:
    -   It uses a gradient background and decorative blurred shapes for visual flair.
    -   It wraps the content in a `Container` component to maintain consistent page width and alignment.

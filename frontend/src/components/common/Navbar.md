This file defines a simple `Navbar` component.

-   **Functionality**: It renders a top navigation bar with the application's name, which also serves as a link to the homepage.
-   **Components**: It uses a `<header>` element and a `Link` from `react-router-dom` to create the clickable brand logo/name.
-   **Styling**: It has a fixed height, a bottom border, and a white background.

This file defines a `Container` component used for layout purposes.

-   **Functionality**: It provides a responsive, centered container with a maximum width and horizontal padding.
-   **Props**:
    -   `children`: The content to be placed inside the container.
    -   `className`: Additional CSS classes for custom styling.
-   **Usage**: This component is used to wrap page content, ensuring it is well-aligned and does not stretch to the full screen width on large displays.

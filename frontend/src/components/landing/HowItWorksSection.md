This file defines a section for the landing page that explains the complaint resolution process.

-   **Functionality**: It visually breaks down the end-to-end workflow, from a citizen's report to the final resolution, to build user trust and clarify the process.
-   **Content**:
    -   It uses a `SectionHeading` for the title.
    -   It displays a five-step timeline, with each step featuring an icon, title, and description (Submit, Verification, Assignment, Field Work, Resolution).
    -   Below the timeline, it includes three summary cards that reiterate the benefits for citizens, the professional workforce, and the jobs/networking features.

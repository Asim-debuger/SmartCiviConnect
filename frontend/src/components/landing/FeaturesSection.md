This file defines a section for the landing page that highlights the key features of the platform.

-   **Functionality**: It lists the core capabilities of the application to attract users.
-   **Styling**: This section is designed with a dark theme (`bg-slate-950`) to make it visually distinct.
-   **Content**:
    -   It uses a `SectionHeading` component adapted for a light-on-dark theme.
    -   It displays six feature cards in a grid, each with an icon, title, and description. The features include GPS tracking, live workforce tracking, real-time notifications, and more.

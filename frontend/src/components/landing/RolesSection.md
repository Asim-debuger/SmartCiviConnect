This file defines a section that describes the different user roles within the platform.

-   **Functionality**: It clarifies who the platform is for and what each type of user can do.
-   **Content**:
    -   It uses a `SectionHeading` component to introduce the section.
    -   It displays four cards in a grid, each representing a user portal:
        -   Citizen Portal
        -   Officer Portal
        -   Staff Portal
        -   Admin Portal
    -   Each card includes an icon, a title, and a brief description of the portal's function.

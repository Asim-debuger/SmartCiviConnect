This file defines a section that showcases the different categories of civic issues that can be reported.

-   **Functionality**: It informs potential users about the types of problems they can report through the platform.
-   **Content**:
    -   It uses a `SectionHeading` component for the title and description.
    -   It displays a grid of eight category cards.
    -   Each card represents a specific category (e.g., "Road Damage", "Garbage Management") and includes an icon, name, and a more detailed description of the issues covered.

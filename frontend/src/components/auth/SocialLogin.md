This file defines a component for displaying social login options.

-   **Functionality**: It provides a clear visual separator and a button for alternative login methods, such as Google.
-   **Components**:
    -   A horizontal rule with the text "OR" in the middle to separate the main login form from social login options.
    -   A "Continue with Google" button.
-   **Note**: Currently, the button is a placeholder and does not have an `onClick` handler implemented for actual social authentication.

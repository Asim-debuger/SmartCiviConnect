This file provides a consistent layout wrapper for all authentication pages.

-   **Functionality**: It ensures that all authentication forms (like login and registration) have the same centered appearance and background.
-   **Components**:
    -   It uses a `Container` component to wrap the content.
    -   It centers its `children` within a container that has a maximum width (`max-w-md`), making it suitable for forms.
-   **Styling**: It sets a light gray background (`bg-slate-50`) for the entire page and adds vertical padding.
